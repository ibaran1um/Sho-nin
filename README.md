# 承認の儀

60秒間、流れてくる書類にひたすらハンコを押す仕事。変な書類を承認すると会社が変になる。

## 操作
- スマホ：書類をタップで承認 / 左右にスワイプで却下
- PC：クリック・Spaceで承認 / ドラッグ・←→で却下

## 書類を増やす
docs.js に1行1枚で書いてあります。書き方はファイル先頭の説明を見てください。
- NORMAL：まともな書類（承認が正解）
- SUBTLE：一見まともで1か所だけおかしい書類（却下が正解）
- ABSURD：明らかに変な書類（却下が正解）

## ファイリング済（図鑑）
一度でも承認か却下をした書類が記録されます。記録はブラウザ（localStorage）に保存されます。
変な書類は、一度承認すると「承認した結果」が図鑑に載ります。

制限時間や出現率は index.html 内の `CFG`、肩書の基準は `RANKS` で調整できます。
